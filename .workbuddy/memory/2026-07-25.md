## 会话标签页功能（桌面版 opencode）

用户需求：桌面版加标签页，一个标签页对应一个会话，快速切换；替代只能点左侧项目图标列开会话列表侧边栏的方式。确认的设计：全局跨项目标签、放在窗口最顶部（Titlebar 下方全宽条）、设置开关默认开启。

关键架构事实（packages/desktop 是 Electron 壳，UI 全在共享的 packages/app，SolidJS）：
- 当前活动会话 = 路由参数 `:dir`(base64目录) + `:id`，不是 store
- 左侧项目图标列 = `pages/layout/sidebar-shell.tsx` rail；会话列表 = `pages/layout.tsx` 的 SidebarPanel
- `pages/layout.tsx` 的 `syncSessionRoute(dir, id, root)` 是所有会话导航的统一入口（在此处挂标签打开逻辑）
- 持久化：`utils/persist.ts` 的 `merge()` 会把旧数据与默认值合并，新增 store 字段无需迁移
- 可复用标签基建：solid-dnd（`getDraggableId`/`ConstrainDragYAxis`）、`pages/session/helpers.ts` 的 `getTabReorderIndex`、`context/layout.tsx` 的 `getAvatarColors`、`pages/session/session-working.ts` 的 `working()`

实现（全部在 packages/app）：
- `context/layout.tsx`：`SessionBarTab` 类型 + `sessionBarKey` + `sessionBar` store（`{all: []}`，上限 30）及 all/open/close/move/setTitle API
- `components/session/session-tabs-bar.tsx`（新）：标签栏 UI，拖拽排序、中键/按钮关闭、项目色点、工作中脉冲点、未读点、新会话草稿标签（id-less 路由派生，不持久化）、“+”按钮、跨服务器(extra agent)切换导航、按目录预热 sessions 加载、标题清理（去 `[im:x]`/`[scheduled]` 前缀）
- `pages/layout.tsx`：Titlebar 后挂载 `<SessionTabsBar />`；syncSessionRoute 打开标签（跳过 quick-assistant 目录）；archiveSession 关闭标签
- `context/settings.tsx`：`general.sessionTabsBar`（默认 true）
- `components/settings-general.tsx`：GeneralSection 加 Switch 行
- `i18n/en.ts` + `zh.ts`：`settings.general.row.sessionTabsBar.*`、`session.tabs.bar.label`（其他语言回退英文）

## 标签项目色点闪烁修复（同日迭代，未提交）

用户问标签左侧的点是什么：是项目颜色标识（与左侧 rail 项目图标颜色一致），用于跨项目标签区分会话归属。用户观察到切换时色点忽隐忽现——原因：颜色实时查自 `layout.projects.list()`，而项目列表在冷启动/服务器切换（extra agent）时瞬态丢失条目或图标元数据（enrich() 注释里也提到这个竞态）。

修复（颜色缓存到标签记录，与标题缓存同模式）：
- `context/layout.tsx`：`SessionBarTab` 加 `color?: string`；sessionBar API 加 `setColor`
- `session-tabs-bar.tsx` SessionTab：`ownerColor()` 实时优先、`props.tab.color` 缓存兜底；effect 查到实时色即写回缓存。项目换色后实时值会覆盖缓存
- 验证：typecheck 无新增错误，19 pass
