Capture a screenshot of the page currently open in the embedded desktop browser.

Returns a PNG image you can view directly (the bytes are read from disk when
the conversation is assembled) so you can visually verify rendering, layout,
and styling that an accessibility snapshot cannot show. With `fullPage: true`
the capture covers the entire scrollable page instead of the visible viewport.

Use this to check your own work after navigating or interacting (M2-style
self-verification), or to inspect canvas/chart content.

Notes:
- Requires the opencode desktop app.
- The first call asks the user for permission; approving "always" covers
  subsequent screenshots for the session.
- Each screenshot is saved to `.opencode/tmp/attachments/screenshot-<timestamp>.png`
  in the project (the result reports the path). Present it with present_file when
  the user should see it, or reference the path in prompts and other tools.
- Screenshots are for looking, not for reading text: prefer browser_read when
  you need the page structure or element uids.
