# PURPOSE
Create an unattended scheduled agent prompt for the current project.

Use this tool when the user asks the agent to run a prompt once at a specific time or repeatedly on an interval or cron schedule. 

# GUIDELINES

- Use Unix milliseconds for `at` and `interval`, a five-field cron expression for `cron`, and an IANA timezone when the schedule must follow a specific locale.
- `executionMode`:
  1. `automatic_session` is the default. It reuses one session until 30 runs or the current context reaches 1000000 tokens, then starts a new session referencing the previous one.
  2. `existing_session` never rotates.
  3. `new_session` creates unrelated sessions for every run.
