Create an unattended scheduled agent prompt for the current project.

Use this tool when the user asks the agent to run a prompt once at a specific time or repeatedly on an interval or cron schedule. Use Unix milliseconds for `at` and `interval`, a five-field cron expression for `cron`, and an IANA timezone when the schedule must follow a specific locale.

The tool derives the project, directory, current session, agent, and model from the active conversation. `automatic_session` is the default: it reuses one session until 30 runs or 1000000 accumulated tokens, then starts a new session referencing the previous one. `existing_session` never rotates. `new_session` creates unrelated sessions for every run.

This tool creates the scheduled task; it does not run it immediately.
