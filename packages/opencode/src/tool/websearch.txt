# PURPOSE
Search the web using web search provider.

Use this for the following.
- Obtain up-to-date or real time information: use {{year}} for recent info
- Access information beyond knowledge cutoff
- Refine and improve your knowledge on current topics

# GUIDELINES
Use the following parameters; only `query` is REQUIRED.
- `query`: the search query (required).
- `numResults`: number of results to return (default: 8).
- `livecrawl`: how page content is fetched. 'fallback' = use cached content, crawl the live page only when the cache misses (default); 'preferred' = always crawl the live page.
- `type`: how thorough the search is. 'auto' (default), 'fast' = fewer but quicker results, 'deep' = more thorough results.
- `contextMaxCharacters`: max characters of retrieved page content to include in the result (default: 10000).
