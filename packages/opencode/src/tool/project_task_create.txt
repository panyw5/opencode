Create a NEW persisting project-level task for the current workspace.

A project task can be mounted onto one or more sessions.
A project task is different from session-local checklists `todowrite`.

## File structure
Task description in `.project-tasks/<taskID>/prd.md`
Maintain progress record in `.project-tasks/<taskID>/progress.md` (empty when created)
Put other task-related files in `.project-tasks/<taskID>/`

## When to use
- User explicitly wants a NEW project-scoped work item
- You work on a long-horizon task and have already run `project_task_list` and find no existing related project task
- You work on a spin-off task that should separate from the current project task

## When NOT to use
- Update/Edit/Record progress for/End currently mounted task for the session → use `project_task_update` / `todowrite`
- Simple, short-horizon task, short todo checklist (3-5 coding steps) → use `todowrite`
- NEVER create a duplicate project-task with near identical goal


## Rules
- Use concise titles

## WORKFLOW
1. `project_task_list` — avoid duplicates
2. `project_task_create` — only if truly new
3. `project_task_mount` — attach task to current session when working on the task
4. `todowrite` — per-session step checklist
