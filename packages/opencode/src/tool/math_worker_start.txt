Start an OS-detached math-worker child session. The worker is a separate process group and keeps running if Desktop/sidecar exits. Returns { sessionID, pid, state } immediately — do not wait for it. Speculative work still uses the task tool; this is the evidence lane only.

The worker never sees this session. Each round it receives only PROBLEM.md (the shared problem statement), its own TASK file, and the shared math-truth stores, and it cannot read anything outside the problem workspace. This call FAILS unless the problem workspace already carries a complete PROBLEM.md (at least 200 characters, no @file pointer references): on the first dispatch pass the operator's complete problem statement — every definition, formula, notation, and constant convention, verbatim — via the problem parameter (it is persisted as PROBLEM.md; a differing existing PROBLEM.md is refused), and stage any large background files (notebooks, long tables, source documents) via the references parameter (paths relative to this session's workspace); they are copied into references/ with PROVENANCE.json. Keep each task body self-contained: never point at "the given definition", the parent session, an @file mention, or files outside the problem workspace.
