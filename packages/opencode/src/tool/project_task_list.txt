List project-level tasks for the current workspace/worktree.

Returns title, status, sessionCount, and aggregated session-todo progress

## When to use
- [Mandatory] Before creating a task (check for duplicates / existing coverage)
- [Mandatory] Before project task `get` / `mount` / `update` — discover taskIDs
- User asks what project tasks exist or their progress

## Rules
- Archived tasks are hidden from `project_task_list` unless `includeArchived=true`
