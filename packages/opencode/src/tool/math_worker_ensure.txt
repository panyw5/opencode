Ensure an existing detached math-worker is running. If its PID is alive this is idempotent. If it died unexpectedly, restart a new process generation using the same session ID, TASK file, transcript, and truth store. A deliberate stop marker prevents restart. A content-blocked lane (submission not accepted, round without progress) must receive a substantively revised TASK before it can be restarted; never retry the unchanged blocked TASK. Infrastructure blocks (verifier or process errors) may be retried unchanged a bounded number of times before the TASK or environment must change. Use this instead of math_worker_start when recovering an existing worker.
