Update an existing scheduled task by ID.

Use this tool when the user asks to change an existing scheduled task, such as renaming it, editing its prompt, rescheduling it, changing its model or reasoning/thinking intensity, changing its session execution mode, or enabling/disabling it. Obtain the task ID from scheduled_task_list.

Provide at least one of name, prompt, schedule, executionMode, model, or enabled. Changing the schedule or enabled state recomputes the next run time. `automatic_session` reuses the current task session until 30 runs or 1000000 accumulated tokens, then rotates and references the previous session; `existing_session` never rotates; `new_session` clears the binding and creates unrelated sessions.
