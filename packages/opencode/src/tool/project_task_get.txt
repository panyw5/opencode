Get one project-level task with linked sessions and each session's todos/progress.

## When to use
- Inspect a known taskID before updating, mounting, or reporting status
- See which sessions are mounted and their todo progress
- Prefer this over guessing from chat history

## When NOT to use
- Discovering which tasks exist → `project_task_list` first
- Creating a new task → `project_task_create` only after list shows no match
- Changing fields → `project_task_update` with the same taskID

## Rules
- Always use a real taskID from `project_task_list` / create / mount tool output (exact string from the return)
- If you only know the title or an id from chat/inject text, call `project_task_list` first — do not hand-copy IDs
- If the user asks to finish work, call `project_task_update` on this taskID — do NOT create a second task; do NOT mark done without user request or explicit approval
