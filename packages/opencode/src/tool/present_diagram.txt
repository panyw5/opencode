Present an SVG or Mermaid diagram directly in the conversation without creating a file. Use `syntax: "svg"` for a complete SVG document or `syntax: "mermaid"` for Mermaid source such as flowcharts, sequence, class, state, or ER diagrams. Pass raw source without Markdown code fences. Use this for a small number of diagrams that materially help the user understand the result. If the diagram already exists as a file, prefer `present_file` instead.
