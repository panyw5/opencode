# PURPOSE
Read a file or directory from the local filesystem.

# GUIDELINES
- `filePath` parameter uses absolute path.
- Returns up to 2000 lines from the start of the file by default.
- The `offset` parameter is the line number to start from (1-indexed). To read later sections, call this tool with a larger `offset`.
- Use the `grep` tool to find specific content in large files or files with long lines.
- To find the correct file path, use the `glob` tool to look up filenames by glob pattern.
- Contents are returned with each line prefixed by its line number as `<line>: <content>`. For directories, entries are returned one per line (without line numbers) with a trailing `/` for subdirectories.
- Any line longer than 2000 characters is truncated.
- Call this tool in parallel when you know there are multiple files you want to read.
- This tool can read image files and PDFs and return them as file attachments.
