# Construct toy examples

Use low-dimensional, low-degree, canonical, or highly symmetric cases to expose the mechanism of a target claim.

For every candidate:

1. Verify every assumption explicitly.
2. Verify the claimed conclusion in the example without executable computation.
3. Identify where each assumption is used.
4. Extract an invariant, repeated pattern, or possible proof move.
5. Distinguish observed intuition from a proved general statement.

Publish informative examples with `gm_add(kind="example")`, recording the construction, assumptions satisfied, conclusion check, relevance, and observed pattern. An example is shared awareness, not a proof brick. Submit any general lemma extracted from it through `fact_submit` before reuse.
